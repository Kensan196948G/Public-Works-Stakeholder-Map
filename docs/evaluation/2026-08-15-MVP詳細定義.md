# MVP / Prototype 詳細定義（2026-08-15 版・合意用ドラフト）

> 本ドキュメントは、Public Works Stakeholder Map（pwsm）の MVP / Prototype として
> 「何を・誰に・どの URL で・どうデモするか」を定義し、関係者レビューと合意を得るためのドラフトです。
> 本番運用化（実データの一般公開・通知配信・本番負荷試験の本番実施）は対象外とし、
> 承認後に個別フェーズとして進めます。

---

## 1. プロダクトの位置付け（pimm との関係を含む）

| 項目 | pwsm（本システム） | pimm（関連プロジェクト） |
|---|---|---|
| 名称 | Public Works Stakeholder Map | Public Infrastructure Maintenance Map |
| URL | https://pwsm.mirai-dx-platform.com | https://pimm.mirai-dx-platform.com |
| 役割 | 工事の**関係機関（組織）**を整理 | インフラ**資産（もの）**を探す |
| 対象 | 発注者・道路/河川/港湾管理者・警察・自治体窓口 | 橋梁・道路・港湾・河川・公共施設 |
| 公開 | 本番は Cloudflare Access で関係者限定 | 一般公開 |
| 補完関係 | 工事条件から事前協議候補を組み立てる | 工事対象インフラの所在地・属性を確認する |

> どちらも `mirai-dx-platform.com` ドメイン配下。機能を重複実装せず、
> pwsm は「地域・工事条件から関係機関候補を組み立てる」責務に集中する（README §関連プロジェクト）。

## 4. デモ手順（関係者向け）

```bash
# 1. 起動（fixture モード・架空データで全機能を確認）
npm ci
npm run webui
# → http://localhost:<自動選択ポート>/

# 2. 主要デモフロー
#   a. 「デモ地点」で「みらい市中央地区（デモ）」を選択
#   b. 工事対象「道路」・作業内容「掘削」をチェック → 「候補を検索」
#   c. 候補カード（4 件）で「協議候補」「要照会」「対象外」を操作
#   d. 候補詳細（窓口・連絡先・管轄区域）を展開
#   e. 「CSV 出力」「印刷/PDF」で免責・出典・データ版を含む出力を確認
#   f. 「フィードバック」で報告 → 受付番号を確認
#   g. 「データソース」「取込レビュー」「品質」「監査ログ」で管理機能を確認

# 3. 自動検証（全 PASS を確認）
npm run lint && npm run typecheck && npm test && npm run build
npm run data:validate
E2E_PORT=<空きポート> npm run test:e2e   # 7 シナリオ
BASE_URL=http://localhost:<port> npm run load:test  # p95 2 秒以内
```
