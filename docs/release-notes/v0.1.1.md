# 🚀 Release Note — v0.1.1（カスタムドメイン + Cloudflare Access + 監視有効化）

| 項目 | 内容 |
|---|---|

| 🌐 本番 URL | https://pwsm.mirai-dx-platform.com （Cloudflare Access 保護） |

## 📦 変更内容

1. **カスタムドメイン**: Worker `pwsm-api` を `pwsm.mirai-dx-platform.com` へ接続（`wrangler.toml` の `routes` / `custom_domain`。DNS・TLS は Cloudflare 管理）
2. **workers.dev 無効化**: 非保護の `pwsm-api.kensan1969.workers.dev` 経路を廃止し、Access 保護されたカスタムドメインへ一本化（`workers_dev = false`）。preview（`pwsm-api-preview`）は workers.dev を継続
3. **Cloudflare Access（Zero Trust）**: self-hosted アプリ `pwsm` を作成し、組織標準ポリシー（`mirai-const.co.jp` メールドメイン + 管理者メール許可・セッション 24h）でサイト全体を保護
4. **Workers Logs 有効化**（Issue #23）: `[observability] enabled = true` — 本番ログ・エラー率・レイテンシを照会可能に

## 🔐 アクセス制御

- 未認証アクセスは Cloudflare Access のログイン（One-time PIN 等）へリダイレクトされる
- 許可対象: `mirai-const.co.jp` ドメインのメール、管理者メール（既存 11 アプリと同一の組織標準パターン）
- デモデータ（架空）の検証公開のため、関係者限定公開が適切と判断

## ⚠️ 移行上の注意

- 旧 URL `https://pwsm-api.kensan1969.workers.dev` は**本リリースで無効化**（アクセス不可になる）
- API 利用も Access 認証が前提となる（サービス間連携が必要になった場合は Service Token を別途検討）

## ↩️ Rollback

- `wrangler versions deploy` で旧 version へ切替（ドメイン設定は wrangler.toml 由来のため、完全に戻す場合は v0.1.0 タグの設定で再デプロイ）
- Access アプリの削除・無効化はダッシュボード / API から即時可能（データ影響なし）
