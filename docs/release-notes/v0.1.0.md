- 🚨 **エラー整形**: RFC 9457 Problem Details

## 🏗️ 本リリースでのインフラ構成変更

- Web（Vite + React）を **Workers Static Assets** として API と同一 Worker へ統合（`[assets]`・SPA fallback・`run_worker_first = ["/api/*"]`）
  - Web は相対パス `fetch('/api/v1/…')` で API を呼ぶため、単一オリジン統合により CORS 不要
- default env = 本番（`APP_ENV=production`）、`[env.preview]` = `pwsm-api-preview`（検証済み）
- ローカル開発は `.dev.vars`（gitignore 済み）で `APP_ENV=local` を上書き
