# v0.5.0（2026-08-12 予定）— 本番運用評価とセキュリティ・監視・管理改善

## 変更内容

### セキュリティ（重大・高）

- CSP 実装（`default-src 'self'`・`frame-ancestors 'none'`・地理院タイルのみ許可）— 設計 §12.1 の欠落を解消
- 公開/管理 API のレート制限（search 60・geocode 30・feedback 20・admin 60 回/分・429 + Retry-After）
- リクエストボディ上限 64KB（Content-Length + チャンク転送対応・413）
- `Sec-Fetch-Site: cross-site` の状態変更リクエスト拒否（CSRF 強化）

### 機能

- フィードバック管理（FR-017 対応クローズ）: 管理者向け一覧 API `GET /api/v1/admin/feedback` と管理 UI
- フィードバック対応状態の更新（`PATCH /api/v1/admin/feedback/:id`・new/reviewed/resolved）
- 機関詳細 API（`GET /api/v1/organizations/:id`・FR-005）と候補カードの詳細表示（窓口・連絡先・管轄区域）
- 情報源リンク生存確認スクリプト `npm run link:check`（FR-015 第一歩）

### 監視・CI/CD

- ハートビート監視 workflow（Issue #57）: ops-maintenance の無音停止を 8 日以内に検知し Issue 起票
- CI に DB マイグレーション・seed 検証ジョブを追加（PostGIS コンテナ・整合性件数・空間検索）
- Neon 統合テスト（組織詳細・監査チェーン）を追加（`TEST_DATABASE_URL` ゲート。CI は PostGIS で psql 検証）
- ESLint 設定の安定化（`.worktrees/`・`.tmp/` 除外・tsconfigRootDir 固定）

### セキュリティ（追加）

- 監査ログの SHA-256 連結チェーン（migration 0003・既存行バックフィル・`GET /api/v1/admin/audit-events/verify`）
- JWT パーツの厳格な base64url 形式検査

### UX・アクセシビリティ

- スキップリンク（WCAG 2.4.1）・フォーカス可視化（2.4.7）
- 地図のロール付与と代替入力案内・meta description・印刷時 UI 非表示

### 性能・テスト

- 簡易負荷テスト `npm run load:test`（p95 2 秒目標・ローカル実測 87ms）
- E2E にアクセシビリティ（スキップリンク）・機関詳細のシナリオを追加
- MapLibre を vendor チャンクへ分離し、ビルド警告を運用上の許容値として明示
