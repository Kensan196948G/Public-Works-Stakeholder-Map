## ✨ 新機能

- 🔎 **候補一覧の絞り込み・並び替え（FR-008）**: 種別・信頼度・確認状態・期限超過のみ・推定区域のみで絞り込み、既定順/信頼度順/名称順/確認期限順で並び替え。クライアント側即時適用で、絞り込み中も「表示 N / M 件」を明示
- 🖨️ **印刷・PDF 出力（FR-010 完成）**: 免責・データ版・ルール版・出力日時・出典・利用者判断・メモを含む専用テーブルを `@media print` で出力（CSV と同じ情報設計）
- 💬 **フィードバック（FR-017）**: 情報の誤り・リンク切れ・機関不足・UI改善を報告可能。`workflow.feedback_messages` へ永続化（DBモード）、受付番号を発行。本文・URLは監査ログへ残さない
- 🔗 **検索条件の URL 共有（設計 §10）**: 緯度経度・半径・工事対象・作業・周辺影響・目的を URL クエリ化。共有リンクから同一条件で検索を再現（実案件名・個人情報は含めない）
- 🗺️ **管轄区域の地図ハイライト（FR-003 拡張）**: 検索結果の候補機関が持つ公開管轄区域を `GET /map/jurisdictions`（GeoJSON）で取得し、MapLibre 上でオレンジ表示
- 📤 **チェックリスト JSON 入出力**: 端末間バックアップ・復元（7日TTL・形式検証つき）

## 🔧 API 追加

- `POST /api/v1/feedback`（公開・202 Accepted・受付番号返却）
- `GET /api/v1/map/jurisdictions?organizationIds=...`（公開・1〜50 ID・FeatureCollection）

## 🛡️ セキュリティ・性能

- **Origin 検査**: 状態変更 API へのクロスオリジン POST を 403 で拒否（CSRF 対策・ブラウザのみ）
- **キャッシュヘッダー**: `metadata`・地図GeoJSON は `public, max-age=300`、health は 60 秒。管理系は `no-store`
- フィードバックは個人識別情報を収集せず、監査ログへ本文・URLを記録しない（§12.2）
