## ✨ 新機能

- 🔎 **住所検索オートコンプリート**: 都道府県など 2 文字以上の入力で、400ms の debounce 後に候補が自動表示され、クリックまたは ↑↓ + Enter で選択できる（緯度・経度へ自動反映）
- ⌨️ キーボード操作: ↑↓（候補移動）・Enter（確定）・Esc（閉じる）
- ♿ ARIA combobox パターン準拠（listbox / option / aria-activedescendant）

## 🔧 実装メモ

- 既存 `GET /api/v1/geocode`（国土地理院 住所検索API）をそのまま利用（API 変更なし）
- リクエスト連番で遅延応答の上書きを防止・候補選択直後の自動再検索を抑止
- 「住所検索」ボタンは即時検索として維持（障害時の再試行経路）
- 住所クエリは従来どおり監査・ログへ記録しない（プライバシー最小化）

## 📝 設計判断

- **デモ地点セレクトは維持**: デモ seed の管轄ポリゴンは架空座標のため実在住所とヒットしない。実データ整備（Phase 2）完了までデモ検証の主経路として必要。削除は Phase 2 で実施
