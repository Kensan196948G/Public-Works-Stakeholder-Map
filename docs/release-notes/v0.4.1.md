## ✨ 主な変更

- 🔐 **認証・RBAC 基盤（Issue #34・PR #43）**: Access JWT を RS256 で検証し、editor/reviewer/admin の操作別最小ロールを API 側で強制。**既定は無効**（`AUTH_ENABLED=false`）のため本番動作は従来どおり。有効化手順は `docs/operations/auth-rbac.md`
- 🗂️ **情報源台帳の Neon 登録（Issue #32 第一段・PR #44）**: 代表3地域の公式情報源 15 機関を冪等 seed で dev/main 両ブランチへ登録（全件 license 付き・実データの組織/管轄整備は次段）
- 📄 **ライセンス整備（Issue #36・PR #42）**: MIT License / CONTRIBUTING / SECURITY を追加
- 🩹 v0.4.0 の本番スモークで検出した `/map/jurisdictions` 非UUID 500 は PR #40 で修正済み（v0.4.0 に含む）

## 🗄️ DB 変更

- migration: なし（v0.4.0 の `0002_feedback.sql` 適用済み）
- seed: `db/seeds/registry/0001_source_registry.sql` を dev/main へ適用済み（additive・冪等）
